Sample Data

This repository is part of the AnalyticsEngineering-FabricPowerBI GitHub project, which hosts resources for Analytics Engineering with Microsoft Fabric and Power BI.

This repository contains the sample data used throughout Analytics Engineering with Microsoft Fabric and Power BI.
The files are based on Microsoft's Wide World Importers (WWI) sample dataset and have been modified for the examples in this book. Modifications include additional columns, adjusted values, and other changes that help demonstrate Microsoft Fabric features and analytics engineering concepts.
Downloading the Files

Click the Code button.
Select Download ZIP.
Extract the ZIP file to a local folder or OneDrive location.

You can also clone the repository if you are familiar with Git.
Using the Files
The sample files are used throughout the chapters in this book. Most examples assume the files have been downloaded and are accessible from either:

A local folder on your computer
A OneDrive location
A location you can upload into Microsoft Fabric

Specific instructions for using the files are provided in the relevant chapters.
